Undefeated Stars

An online store for trading card games and collectibles in Mexico, built from the catalog to the payment webhook.

In development
  • JavaScript
  • Node.js
  • Express
  • PostgreSQL
  • Supabase
  • Mercado Pago

Undefeated Stars is an online store for trading card games and collectibles aimed at the Mexican market, with a “liquid glass” look: translucent surfaces, soft blur and thin borders that catch the light. The first phase is a complete store: catalog, cart, checkout, accounts, points for discounts and a basic admin panel.

The store never trusts the browser: prices, totals, discounts and stock are recalculated on the server from the database, and only a verified Mercado Pago webhook can mark an order as paid.

Behind the project

What it covers
  • Storefront Catalog, product pages, a cart and checkout, all sharing one header, footer and product card.
  • Accounts Sign up, log in and password recovery with Supabase Auth, plus a profile and saved addresses.
  • Payments The server creates a Mercado Pago Checkout Pro preference from database prices and stock. A signed webhook, checked against the Mercado Pago API, confirms the payment and turns the stock reservation into a sale.
  • Inventory Stock is reserved while a payment is pending, and every movement is recorded.
  • Admin panel Product and order management for the store owners, with an audit log of what each admin changed.
Technical Development

The frontend is plain HTML, CSS and JavaScript, with no frameworks or bundlers: a deliberate choice to learn the fundamentals before reaching for tools. Design values live in one tokens file, so changing the brand means editing one place.

The backend is Node.js with Express, and PostgreSQL runs on Supabase. Only Express talks to the database, with parameterized queries; the browser never reads a table directly. Row Level Security is on for every table.

A Cloudflare Worker serves the static site and forwards /api requests to Express, so the browser sees a single origin and session cookies stay first-party.

Tests run with Node's built-in test runner and cover checkout, the Mercado Pago webhook, authentication, the cart and the proxy.

Rules it is built on
  • Never trust the client Price, total, discount and stock sent by the browser are ignored; the server recomputes them.
  • Cost stays private Public endpoints list their columns explicitly, so what a piece cost the store never leaves the server.
  • All or nothing Creating an order, handling a payment webhook or issuing a refund runs inside a database transaction.
Project Status

In development, and only phase one. The store is not public yet, and the payment flow has not been validated end to end: the webhook has only been simulated locally. Digital packs and an in-app economy are designed but deliberately not started. The source code is private.
