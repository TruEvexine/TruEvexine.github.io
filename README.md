# Rogelio Emmanuel Ceja — Portfolio

Personal portfolio of a Systems Engineering student at UVAQ who builds websites and narrative games.

**Live:** https://rogelioemmanuel.com

- **Pages:** Home, Profile (tech stack + education), Projects, SIN GUARDAR and Project Miralta case studies, Contact, 404
- **Stack:** HTML, CSS and vanilla JavaScript, with no build step for the site itself
- **Languages:** English at `/`, Spanish at `/es/` (texts live in `js/layout.js`; `npm run build:es` regenerates `es/` and `npm run verify` fails if it is stale)

## Structure

```
*.html          Pages (kept at the root so URLs stay clean: /contact, /cotizar…)
es/             Spanish pages, generated by _dev/build-es.mjs (do not edit)
css/            Stylesheets (layout.css = tokens/base, one file per page/component)
js/             Scripts (layout.js = shell + i18n dictionary, one file per page/feature)
partials/       header.html and footer.html, fetched by js/layout.js
data/           projects.json and cv.json (content for cards and CV)
assets/         Images, fonts, icons, CV PDFs (cv/ is generated by the CV PDFs workflow)
docs/           Planning and dev notes
DESIGN.md       Design system reference (palette, type, components, rules)
_dev/           Build, verify and test scripts (not published)
_headers, robots.txt, sitemap.xml, wrangler.jsonc, .assetsignore   Hosting config
```

Run locally with `npx wrangler dev` (it serves the site like Cloudflare does, with clean URLs such as `/cotizar`; header and footer are loaded with `fetch`, so a local server is required).

Tech logos in `assets/icons` come from [Devicon](https://devicon.dev) (MIT); UI icons in `assets/ui` from [Simple Icons](https://simpleicons.org) (CC0). Dev notes live in `_dev/` (not published).
